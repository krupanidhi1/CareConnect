# CareConnect FSD archive review

## Changes made in this review

- Removed the unused Base44 Vite plugin from the frontend manifest and regenerated the frontend lockfile offline. The React app now uses the standalone Vite configuration and Express API client.
- Reconciled the frontend request payloads for donations, requirements, volunteer applications and opportunities with the Express controller field names.
- Added backend serializer aliases for requirement quantities and due dates so the current UI can display progress correctly.
- Added volunteer availability and organisation references to application records; the organisation dashboard can now create opportunities and review applications.
- Added organisation verification submission using HTTPS document links; the admin review dialog displays those links. Direct file uploads are not implemented.
- Added phone OTP controls to Profile using the existing Express phone OTP endpoints.
- Corrected donation and application status transitions, one-time delivered quantity accounting, approved-organisation checks, requirement quantity validation and volunteer place tracking.
- Added public-data filters so unverified organisations and their requirements/opportunities are not shown to visitors.
- Added refresh-token hash storage, rotation checks and revocation on logout/password changes.
- Updated Nodemailer to `^10.3.1`; the basic `createTransport`/`sendMail` service calls remain the same, but SMTP delivery has not been tested here.
- Removed placeholder contact details and unsupported impact claims. Updated the interface to use genuine Wikimedia Commons photographs with attribution.
- Removed Base44-specific frontend build instructions and editor-only image hooks.

## Static checks executed

- Backend and test JavaScript files: `node --check` parse validation.
- Frontend source: TypeScript parser used in JSX mode for `.js`/`.jsx` syntax validation.
- Frontend local import paths: checked for unresolved relative and `@/` imports.
- Package manifests and frontend lockfile: JSON parsed; frontend root dependencies matched to the manifest.
- Archive contents: source folders and environment templates checked; no real `.env` secrets or `node_modules` are packaged.

## Not executed in this environment

- `npm install` / `npm audit` against the npm registry.
- Full Jest + MongoMemoryServer integration suite.
- Current Vite production build after the latest source edits.
- SMTP/Twilio delivery against real provider credentials.
- End-to-end browser testing with a running MongoDB and backend.

The final ZIP is therefore a corrected source package with static checks, not a claim that all runtime workflows have been fully tested. Run the commands in the root README on your MacBook before submitting.

## Remaining product limitations

- Monetary contributions are recorded as pledges; no payment gateway is integrated.
- Organisation verification uses HTTPS document links, not direct uploads.
- Wikimedia Commons photographs are remote URLs, not local image binaries in this ZIP.
- Backend and root test-runner lockfiles need to be generated by running `npm install` in those directories because npm registry access was unavailable during packaging.
